# Branding assets

Place the following files in this directory:

- `Logo.png` — website logo, nominal size 320 × 70 pixels;
- `LogoIcon.png` — square icon, nominal size 32 × 32 pixels;
- `Home_wellcom.gif` — animated home-page image, nominal size 550 × 714 pixels.

The spelling `Home_wellcom.gif` is retained to match the requested asset name. The file extension must be `.gif`, not `.gift`.
